## About

Hi, I'm **Alex Purification**. I enjoy building software from the data layer to the user interface: designing database relationships, developing APIs, implementing authentication, and creating responsive experiences.

My projects include full-stack applications, management systems, Django applications, React interfaces, and experiments in building web frameworks and browser tooling. I focus on learning through hands-on projects and writing code that is understandable and maintainable.

- **Current focus:** Full-stack JavaScript, backend engineering, and AI-enabled web applications
- **Backend:** Node.js, Express, PHP, Laravel, Python, Django, Django REST Framework
- **Frontend:** JavaScript, React, HTML, CSS, Tailwind CSS, Bootstrap
- **Data:** MySQL/MariaDB, SQLite, MongoDB/Mongoose fundamentals
- **Interests:** API design, application architecture, authentication, testing, and database design

```text

        ↓
Model the data and define boundaries
        ↓
Build small, testable features
        ↓
Connect APIs, UI, and persistence
        ↓
Validate edge cases and security
        ↓
Document, deploy, and iterate
```

## How I approach development

<div align="center">

**Understand → Design → Build → Test → Document → Improve**

</div>

- **Start with the use case:** build features that solve a clear problem.
- **Separate responsibilities:** keep interface, API, business logic, and data access understandable.
- **Consider security early:** validate inputs, protect private routes, and handle authentication deliberately.
- **Test behavior:** verify important success paths, failure paths, and edge cases.
- **Document for the next developer:** explain setup, configuration, endpoints, and limitations.
- **Use AI thoughtfully:** review generated output and keep consequential actions under user control.

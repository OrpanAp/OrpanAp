## About me

I'm **Alex Purification**, a software developer focused on building practical web products across the frontend and backend. I enjoy understanding how an application works end to end — from its user interface and API contracts to authentication, data modeling, and persistence.

Most of my experience comes from hands-on projects: building management systems, REST APIs, content-driven websites, React interfaces, and experiments with custom web tooling. I value learning by building, breaking problems into smaller parts, and improving code through testing and iteration.

- **Currently focused on:** JavaScript, TypeScript, React, Node.js, and Express
- **Backend experience:** PHP, Laravel, Python, Django, REST API development
- **Data technologies:** MySQL / MariaDB, SQLite, MongoDB, and Mongoose
- **Engineering interests:** API design, authentication, application architecture, testing, and database design
- **Exploring:** AI integration in useful web applications

I'm looking for opportunities where I can contribute, learn from experienced developers, and grow through real product work.

## How I build

<div align="center">

**Understand → Design → Build → Test → Document → Improve**

</div>

I aim to approach projects with a few consistent principles:

- **Solve the real problem:** understand the use case before adding complexity.
- **Keep responsibilities clear:** separate UI, API, business logic, and data access where appropriate.
- **Treat security as part of the feature:** validate input, protect private routes, and handle authentication carefully.
- **Build for maintainability:** prefer readable code, small steps, and reusable components.
- **Keep learning:** use documentation, test assumptions, and review AI-generated suggestions rather than accepting them blindly.

## How I work

1. **Understand the problem** and define the expected behavior.
2. **Design the data and API boundaries** before adding complexity.
3. **Build in small, testable increments** with clear responsibilities.
4. **Validate edge cases and access control** rather than relying only on the happy path.
5. **Document and iterate** based on what the project needs next.

I'm continuing to deepen my skills in full-stack JavaScript, backend architecture, automated testing, database performance, and integrating AI capabilities into useful products.
